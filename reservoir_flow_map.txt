BUG IN CURRENT TVL QUERY
- Price comes from call traces (currentprice / converttoassets). Days with no call fall back
  to COALESCE(price, 1) -> TVL dips ~15% on those days. Fix: forward-fill last known price,
  or compute from Deposit/Withdraw events (assets/shares).

BUILD PLAN
1. Balances: daily balance per holder per token from Transfer events (3 tokens).
2. Buckets: classify each holder dynamically (contract vs EOA; contract name/project from
   Dune contracts + labels tables; Morpho markets where collateral or loan token = our tokens).
   Buckets: Morpho, Pendle, Euler, Dolomite, IPOR, Curve/DEX, bridges (OFT adapters), wallets.
3. Split Morpho singleton by market via Morpho events.
4. Daily net change per bucket = the "what left and where" view. Mint/burn = entered/exited protocol.
5. Reconcile: sum of buckets = total supply = existing TVL query = app number.
